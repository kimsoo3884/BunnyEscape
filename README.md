# BunnyEscape

Unity로 제작한 2D 플랫폼 게임의 Windows 플레이용 빌드입니다.

## 다운로드 및 실행

1. **Code → Download ZIP**으로 저장소를 다운로드하고 압축을 해제합니다.
2. **Builds/Bunny Escape.zip**을 전체 압축 해제합니다.
3. **Bunny Escape/bunny.exe**를 실행합니다.

실행 파일과 bunny_Data 폴더, UnityPlayer.dll 등 함께 제공된 파일은 같은 위치에 유지해 주세요.
